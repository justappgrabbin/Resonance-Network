# Stellar Proximology

Stellar Proximology is the public / ChatGPT-facing second face of the sovereign Resonance Network.

## Canonical architecture

- **Resonance Network** — sovereign/local owner of the capability and portable user profile.
- **Stellar Proximology web face** — public onboarding and lightweight use.
- **Stellar Proximology ChatGPT plugin** — optional ChatGPT adapter over MCP.
- **Cynthia** — cognition/interpretation layer, distinct from Human Design and astrology.
- **Human Design + astrology** — deterministic calculation and structured interpretation capabilities.

The hosted face is not the authority for a person's profile. Profiles are intended to remain portable and exportable.

## Working rules

1. Calculate first, interpret second.
2. Never silently replace verified architecture with guessed architecture.
3. Keep Human Design, astrology, Cynthia, and Resonance as distinct layers.
4. Preserve local-first / sovereign operation.
5. Treat the public site and ChatGPT plugin as adapters, not the source of truth.
6. Never treat “deployed” as “working”; visible render and usable flows are the acceptance criteria.
7. Preserve append-only lineage for major architectural decisions and corrections.

## Multi-account recovery

This branch exists as an account-neutral recovery point. Either ChatGPT account can be pointed at this repository/branch to recover the current architecture, release metadata, plugin configuration, and source-of-truth hashes without relying on one account's chat memory.
