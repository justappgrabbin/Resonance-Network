# Stellar Proximology Architecture

Stellar Proximology is a second face of Resonance Network, not the sovereign computer.

```
                     Resonance Network
                    sovereign host/core
                           |
          +----------------+----------------+
          |                |                |
       Cynthia       Human Design       Astrology
          |                |                |
          +----------------+----------------+
                           |
                 shared capability model
                           |
                +----------+----------+
                |                     |
       Stellar web face        ChatGPT plugin
```

## Sovereignty requirements

1. Core calculation and profile functionality must not depend on ChatGPT.
2. User profiles must be exportable/importable and remain user-owned.
3. The hosted face may calculate and interpret, but it is not the canonical owner of profile identity.
4. ChatGPT is an optional cognitive/orchestration surface.
5. MCP is an adapter boundary, not the core application.
6. If the hosted face disappears, the sovereign package must still be recoverable and usable.
7. Existing source modules should be wired before replacements are invented.

## Capability families

- Human Design chart calculation and BodyGraph structures
- Gate / line / color / tone / base substructure
- Tropical, sidereal and draconic astrology
- Relationship comparison
- Timing / transit context
- Cynthia/shared cognition
- Local/portable profile model
- Web API and ChatGPT/MCP adapter surface
