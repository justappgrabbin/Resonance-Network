## v13 Purpose Fulfillment

First contact is now Cynthia-led for a new or unfinished local profile.

Cynthia asks about the person's name, what shaped them, current self-understanding, purpose, present life, desired life, happiness/dissatisfaction, blockers, strengths and recurring interests.

Those answers:
1. persist locally under `resonance:purpose`;
2. are best-effort landed into the same Foundation journal;
3. remain ongoing pathway state rather than disposable chat.

Purpose follows the **one-calculation law**:
- if the Resonance origin calculation already exists, Purpose reuses it;
- otherwise Cynthia routes to the existing Profile/origin calculation once;
- `consciousness.calculateProfile` remains the one Human Design + astrology calculation;
- Purpose does not create a duplicate chart engine.

The first pathway uses the person's own answers to choose a practical mode — `Discover`, `Unblock` or `Experiment` — then uses their saved Human Design Type, Strategy, Authority and Profile as a decision/navigation lens. The visible result is ordinary language: current state, desired state, friction, next move, decision check and what evidence to bring back from reality.

Learning loop:

`possibility -> action -> observed outcome -> discrepancy/evidence -> next pathway`
